# keel_permit (Data Source)

Query Keel permits, newest first (one page of up to 200). Scoped to the project of the provider's API key, which may have admin or client scope.

Use this data source to read recent Keel permit decisions in the project of the provider's API key. Optional filters narrow results by decision (`allow`, `deny`, `review`, or `throttle`) and limit the number of returned permits (1-200). `decision = "challenge"` is a deprecated alias for `review`.

## Example Usage

```terraform
data "keel_permit" "last_denied" {
  decision = "deny"
  limit    = 1
}

data "keel_permit" "held_for_review" {
  decision = "review"
  limit    = 20
}
```

- `reason_detail` (String) The permit's decision_details object (decision, code, reason and any additional details) as a JSON string, if present.
