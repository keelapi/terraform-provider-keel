# keel_api_key (Resource)

Manages a Keel API key. API keys are immutable after creation — any change forces replacement. Deletion revokes the key.

Use this resource to create API keys in the project of the provider's API key, which must have admin scope. API keys are immutable after creation; changing configurable fields forces replacement, and deletion revokes the key. The key's secret (`raw_key`) is returned only when the key is created.

Keys with `scope = "approval"` exist only after dual-control approval: Keel refuses them unless the project enforces dual control, and otherwise holds each request for a second approver. Terraform cannot wait for that approval, so the apply fails with the pending change's ID and expiry and nothing is stored.

## Example Usage

```terraform
resource "keel_api_key" "backend" {
  name        = "backend-service"
  description = "Key for the backend service"
  scope       = "client"
}

output "api_key_id" {
  value = keel_api_key.backend.id
}

output "api_key_project_id" {
  value = keel_api_key.backend.project_id
}

output "api_key_prefix" {
  value = keel_api_key.backend.prefix
}
```

## Import

Import with the key ID. Imported keys have no `raw_key`.

```shell
terraform import keel_api_key.backend key_id
```

## Schema

### Optional

- `agent_principal_id` (String) Agent principal to bind the key to, making it that agent's execution credential. Cannot be combined with scope "approval". When the provider's own API key is bound to an agent, Keel binds new keys to the same agent.
- `description` (String) API key description.
- `expires_at` (String) Expiration timestamp, if configured: RFC 3339 with a UTC offset, such as "2027-01-01T00:00:00Z". Keel may return the same instant spelled differently; that is not a change.
- `name` (String) API key name.
- `scope` (String) Key scope: "admin", "client", or "approval". Default: "admin". An approval-scope key exists only after dual-control approval, which Terraform cannot wait for: the apply fails with the pending change's ID and nothing is stored.

### Read-Only

- `created_at` (String) Creation timestamp.
- `created_by` (String) User ID that created the API key, if available.
- `id` (String) API key ID.
- `last_used_at` (String) Last-used timestamp, if the key has been used.
- `prefix` (String) Key prefix (visible portion).
- `project_id` (String) Project the key belongs to: always the project of the provider's API key, because Keel creates, lists and revokes keys within that project.
- `raw_key` (String, Sensitive) The raw API key. Only available at creation time.
- `revoked_at` (String) Revocation timestamp, if the key has been revoked.
- `status` (String) Derived key status: "active" or "revoked".
